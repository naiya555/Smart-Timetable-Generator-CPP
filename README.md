📚 Smart Timetable Generator (C++)

A console-based Smart Timetable Generator built using C++, Object-Oriented Programming (OOP), STL, and File Handling. The application is designed to simplify academic timetable management by organizing subjects, teachers, and lecture schedules while maintaining scheduling constraints.

✨ Features

- Menu-Driven Console Interface
- Object-Oriented Architecture
- Subject Management
- Teacher Management
- Theory and Lab Lecture Support
- Lecture Validation
- Automatic Timetable Generation
- Teacher Conflict Detection
- Smart Lab Scheduling
- Search by Teacher
- Search by Subject
- Timetable Statistics
- File Handling for Data Management
- TXT Export
- CSV Export

🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- File Handling

🎯 Project Objective

To develop a structured and efficient timetable management system that automates academic scheduling, reduces manual effort, and helps prevent teacher and lecture scheduling conflicts.
